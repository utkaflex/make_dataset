# Рукописная выборка

Веб-приложение для сбора 108 цветных образов. Для каждой заглавной латинской буквы A–Z и цифры 0–9 предусмотрено три варианта. Приложение хранит сохранённые рисунки, текущую позицию и настройки в IndexedDB. Node.js раздаёт статические файлы. JSZip 3.10.1 входит в проект.

## Локальный запуск

1. Установите Node.js 24.
2. В корне проекта выполните:

   ```sh
   node serve.mjs
   ```

3. Откройте [http://localhost:8080](http://localhost:8080). Пользуйтесь одним и тем же адресом, чтобы видеть свою выборку. Например, браузер хранит данные для localhost и 127.0.0.1 отдельно.

## Работа с приложением

- Нарисуйте предложенный символ и нажмите **Сохранить и далее**. Вы можете отменить последний штрих или очистить холст. Чтобы заменить сохранённый вариант целиком, откройте его в галерее и очистите холст перед рисованием.
- Галерея позволяет открыть любую из 108 позиций. Режим **Только Apple Pencil** принимает ввод от указателя типа pen.
- Кнопка **Резервный ZIP** скачивает доступные PNG. Кнопка **Скачать итоговый ZIP** становится доступна после заполнения всех позиций. Итоговый архив называется `<UUID>.zip` и содержит `<UUID>/<символ>/<вариант>.png`. Каждый образ имеет размер 128 × 128 и непрозрачный фон.
- Сохранённые образы переживают обычное закрытие браузера. Несохранённые штрихи хранятся в памяти открытой страницы. Очистка данных сайта удаляет выборку. Резервный ZIP содержит изображения для внешнего хранения. Импорт ZIP в приложение не предусмотрен.
- Сброс выборки требует подтверждения и создаёт новый UUID. Настройки кисти и интерфейса сохраняются.

## Деплой на Railway

1. Загрузите проект в GitHub и подключите репозиторий к сервису Railway. Используйте корень проекта. Railway обнаружит `Dockerfile` автоматически.
2. Дождитесь запуска сервиса. Контейнер слушает `0.0.0.0` и порт `PORT`, который предоставляет Railway. Сервисы базы данных и переменные с секретами не требуются.
3. В настройках сервиса откройте **Networking → Public Networking → Generate Domain**. Откройте выданный HTTPS-адрес в Safari на iPad.

При первом открытии нового домена браузер создаёт отдельную локальную выборку.
